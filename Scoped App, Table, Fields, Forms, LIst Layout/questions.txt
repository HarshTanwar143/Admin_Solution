Simple example
On your Project form, the "Skills" field is type List, referencing the Skill table.
When creating a project, you click the field and see a slushbucket/multi-select popup:
Available Skills          Selected Skills
- Java                     - Java ✔
- Python          →        - Node.js ✔
- Node.js                  - AWS ✔
- AWS
- SQL
You pick Java, Node.js, AWS — all three get stored in that one field for that project record, comma-separated internally as sys_ids (e.g., a1b2c3,d4e5f6,g7h8i9).
